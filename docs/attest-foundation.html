Foundation Document

attest — CI/CD for AI agents

A local-first eval runtime: bring any agent callable via CLI or HTTP, run it against test cases, score with deterministic and LLM-based metrics, diff runs, and get interactive dashboards and shareable reports. Open-core, cloud follows.

Decisions locked 2026-08-06 · working title (final name before launch) · solo founder + heavy AI-agent leverage · full startup attempt

1 · Market & Positioning

BeachheadStartup AI product teams (2–20 engineers) shipping agents to production without a CI quality gate. Indie devs adopt the OSS core as a side effect; enterprise pulled in later via the pricing ladder.
PositioningWedge message: “CI/CD for AI agents.” Category vision: agent eval platform. Lead with the CI frame; grow into the platform story.
Why switchvs Braintrust / LangSmith / Promptfoo / DeepEval — see wedge below.

The wedge

Framework-agnostic

Agent contract is CLI or HTTP. Any language, any framework, zero SDK lock-in.

Agent-native

Trajectory & tool-call assertions, multi-turn user simulation — built for agents, not prompt pairs.

Best-in-class reports

Run diffing, regression views, self-contained shareable HTML reports — where OSS rivals are weakest.

Local-first is a property of the product, not the lead pitch.

2 · Core Product Contracts

Agent interfaceCLI command or HTTP endpoint; the runtime invokes it per test case.
Trace contractOpen versioned JSON envelope attest.trace/v1alpha1 — OTel GenAI-mapped attribute names, but insulated from upstream semconv churn. Optional: no trace → output-only eval still works. Framework adapters later are sugar over the same schema.
Test authoringYAML/JSON files are the source of truth (git-versioned, CI-friendly). Local dashboard UI editor writes back via comment-preserving edits.
MetricsDeclarative assertions (contains, regex, JSON-schema, tool-called…) for the 80% case + executable contract: any executable/endpoint receiving {case, output, trace} and returning a score. LLM judges built in, BYO keys at launch.
Dashboardattest view = local web app; attest report = self-contained static HTML export (CI artifact, email, PR link).
v1 evalsSingle-turn · trajectory/tool-call assertions · run diffing (mandatory) · multi-turn user simulation (flagship; ships v0.2 if not solid by launch). Human review queue & judge calibration = v2.

6 · Stack (scouted, founder-decided)

LanguageTypeScript on Bun (founder call, overriding scout's Go rec) — iteration speed, one language across runtime + dashboard, JS-native contributor pool. Bun's --compile + built-in SQLite recover the single-binary story.
Distributionnpm/npx for JS devs and Bun-compiled standalone binaries (GitHub Releases, brew, curl|sh) — keeps the dependency-free wedge. macOS + Linux at launch; Windows = first compat fast-follow.
Run storeSQLite (WAL), project-local .attest/runs.db; versioned migrations; immutable completed runs; exportable run bundles — cloud ingests bundles via API, never syncs SQLite.
DashboardReact + Vite SPA embedded in the artifact; loopback-only server; static report = same components with the run bundle inlined into one HTML file. Virtualized tables + custom trace waterfall; tested at 10k cases.
SimulationSimulator loop is runtime orchestration over the ordinary one-turn agent contract; stateless replay by default; deterministic termination policy.
ReposOne public OSS monorepo (CLI, runtime, web, schemas, docs, conformance fixtures); cloud in a separate private repo; DCO, SBOM, NOTICE hygiene.
TestingDeterminism, contract compatibility, hostile process behavior. Golden conformance fixtures per contract; fake hostile agents; required CI never calls a live LLM.
PhilosophyNovel only in contracts, eval semantics, diffing, report UX — boring everywhere else. No sandboxing v1 (trusted project code + process controls).
Top technical risks: contract churn · unreproducible judge behavior · safe process supervision (timeouts, process-tree kill) · lossless YAML round-tripping · report performance at large trace volume · Bun ecosystem maturity. De-risk prototypes target exactly these before broad build-out.

7 · Implementation Stack (locked)

Runtime & core

SQLite driverPortable: node:sqlite (Node 22+), libsql fallback — npm package runs under both Node and Bun; npx quickstart works for everyone. Resolves the flagged bun:sqlite tension.
MonorepoBun workspaces + Turborepo (task graph + caching across cli / web / schemas / docs).
Lint / formatESLint + Prettier — contributor familiarity and rules ecosystem over Biome's speed.
CLI frameworkCommander — boring on purpose; novelty budget stays in the contracts.
ValidationZod as source of truth → TS types inferred + JSON Schema generated (Zod v4) and checked into schemas/; conversion guarded by golden tests.
DB accessKysely — type-safe SQL over any driver dialect; migrations remain hand-written numbered SQL.
Local serverHono — identical on Node + Bun, tiny, typed; ports to Cloudflare Workers for the cloud tier.
LLM judgesTanStack AI SDK behind attest's own thin judge interface. Risk accepted: very new SDK — contained, swappable (Vercel AI SDK fallback) without touching metric contracts.

Frontend

Data / routingTanStack Router + Query — type-safe routes, polling/cache for live runs; consistent with TanStack Table + AI SDK.
StylingTailwind + shadcn/ui — owned components, fast build-out, clean CSS inlining for static reports.
ChartsTree-shaken Apache ECharts — canvas perf at 10k cases, works inside self-contained report HTML.

Quality & delivery

TestingVitest + Playwright; Node path is the required matrix; no live LLMs in required CI.
ReleasesChangesets + GitHub Actions matrix: npm publish + Bun-compiled binaries (darwin/linux × arm64/x64) + checksums + Homebrew tap bump.
Docs siteAstro Starlight — Phase 0 contract specs land here as launch content.
TelemetryOpt-out anonymous with loud disclosure — command counts / version / OS only, never payloads, prompts, or keys; ATTEST_TELEMETRY=0.

Cloud (directional — built months 5–7)

ComputeCloudflare Workers (Hono ports as-is); heavy run-bundle ingest via Workers Queues.
DatabaseCloudflare D1 (founder call; Neon excluded). SQLite semantics ≈ local schema/migrations reuse — strong symmetry. Accepted constraints: 10GB/db → per-org DB sharding from day one; analytics via scheduled rollups. Revisit trigger: cross-run analytics outgrowing D1.
Object storageCloudflare R2 — large immutable payloads (traces, outputs, report bundles); zero-egress shared reports.
AuthOpen — decided at cloud build time (candidates: Better Auth on Workers, Clerk, CF Access for early beta).

8 · Roadmap

Weeks 1–2
Phase 0 — Contracts & Name
  • Spec agent contract (CLI + HTTP semantics), trace schema v0, config format, metric contract.
  • Final name: candidates + npm/PyPI/domain checks (blocks public README, not development).
  • Specs written as public-ready docs — they double as launch content.
Weeks 2–6
Phase 1 — Core Runtime
  • Runner (parallel CLI/HTTP invocation, timeouts, retries, caching) · assertions engine · executable metrics · LLM judges (Anthropic + OpenAI, BYO keys).
  • SQLite run store · run diffing · CI mode (exit codes, thresholds, JSON/JUnit output).

Cut line: nothing — this is the minimum credible product.

Weeks 6–10
Phase 2 — Dashboard & Agent-Native Evals
  • attest view (runs, drill-down, trace viewer, diff view) · attest report static export.
  • UI test-case editor (writes back to files) · trajectory/tool-call assertions.

Cut line: UI editor slips before trace viewer or diff view do.

Weeks 10–14
Phase 3 — Simulation, Polish, Launch
  • Multi-turn simulation (if not solid by week 12 → v0.2 headline; launch does not slip).
  • <5-min quickstart cold-tested on ~5 devs · README + demo video + example agents · docs site · cloud waitlist.
  • Launch: Show HN + Product Hunt, staged in advance.
Months 3.5–5
Post-Launch — Partners & Distribution
  • 10–20 design partners, weekly feedback loop · framework adapters + example repos · first guides + one public benchmark report.
Months 5–7
Cloud Beta
  • Hosted dashboards, shared links/comments, attest push · team history + cross-run analytics · auth, orgs, seats + usage metering · free/team pricing live, seeded with design partners.

Deferred (pull-based): enterprise SSO/RBAC/audit/self-hosted · managed judge inference · UI-first authoring for PM/QA · trace-schema governance.
