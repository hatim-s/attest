# Compact chart integration

Use a React `key` containing project, source and eval identity on both chart components. Include any explicit trend query-window/filter identity in that key. Preserve it while polling or appending results. Components cannot infer a source change from identical run/day identities. Axis, timezone offset, daily calendar bounds, controlled selection, identity removal and focus departure expire inspection internally.

Map decoded summary DTOs to the bounded models. The DTO boundary/mapper owns unique run IDs, finite epoch-millisecond timestamps, finite rates in [0, 1], and valid fixed timezone offsets. Rendering trusts those inputs. Keep the 200-slice trend cap and 92-day calendar cap, expose server truncation, and use offset 0 for backend UTC activity buckets. Complete eval slices supply their own rate. Run status and aggregate counts do not determine completion or imply case identities. Fixed offsets do not model DST.

Trend readout follows hover or mark focus independently of the chooser and Open run action. Focusing either chooser or action pins the displayed action through appended polling results until departure or invalidation. Dense marks keep exact coordinates and stable native anchors. Their nearest-mark regions are clipped to a 24px radius; blank space has no navigation target. Native links retain browser navigation, including modifiers and middle click, without an activation handler. Equal-coordinate collisions belong to the first sorted identity for pointer input. Inspect run reaches every identity with full timestamp through milliseconds, offset, slice/run status, supplied rate and counts. A density change transfers owned plot focus to the chooser without taking outside focus.

Daily chooser stages inspection; Select day calls `onSelectDay` to commit it. This API selects a day, not a destination route. Empty/already-selected days use a guarded `aria-disabled` action so controlled selection preserves focus. Sparse marks select directly with Enter, Space or click; sparse mode has no action row. All paths ignore the already selected day. Dense touch/pen selection resolves the actual bounded slot at pointer-up, rejects movement over 8px, and suppresses the compatibility click for that gesture. Mouse clicks resolve the current bounded slot independently of hover.

Load the host stylesheet before component styles. Scoped controls supply affordances under its reset. The fixed 140px readout places rate, time/status, comparison/selection warning and counts before long identity. Only the identity row uses ellipsis. Full identity/time/counts remain in the native chooser; Open run has a full-identity title. Controls occupy one fixed 58px row. Hover, inspection and controlled selection do not change plot position within a density mode. Density can change with data or width. Native wrapping, touch readability and geometry require browser validation.

Host `--fail`, `--fail-soft`, `--fail-text` and color-scheme are honored. Scoped fallbacks use #FF5C00/#FF6A1A for full failure marks and #FFC29C/#9A4619 for shortfall. Explicit theme colors provide readable decline text without requiring a build transform or `light-dark()` support. Legacy root theme and `.attest-compact[data-theme]` light/dark/system support remain scoped here.
